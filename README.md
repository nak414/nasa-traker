# nasa-traker
## Project Idea
NASA Tracker is a lightweight application designed to help track satellite locations and upcoming space exploration missions in real time. It assists researchers and astronomy enthusiasts by consolidating flight paths and mission timelines into an accessible dashboard.

## Technologies Used
* HTML5 / CSS3
* JavaScript
* GitHub & GitHub Pages
  
## How to Run
1. Clone or download this repository.
2. Open `index.html` in any web browser.
